# Student Daily Planner & Streak Tracker

A console-based productivity tool that helps students track daily tasks, build completion streaks, log study time, and set reminders — with all data saved permanently using JSON files. Designed to organize schoolwork across subjects including SocSci, Biology, and Chemistry.

## Project Overview

Student Daily Planner & Streak Tracker is designed to help students stay organized and motivated. Users can create daily task checklists grouped by subject, mark items complete, and maintain a completion streak — a running count of consecutive days they have finished tasks. Study sessions can be timed and logged per subject, and reminders help keep track of important deadlines for SocSci, Bio, Chem, and other subjects. All data is stored in JSON format, so progress is always saved even when the program is closed.

### Core Features
- Daily task checklist — add, view, edit, delete tasks by subject
- Completion streak system — tracks current and longest streaks
- Subject-based history and statistics — view progress for SocSci, Bio, Chem separately
- Study timer — record study minutes per subject
- Reminders — set and view upcoming deadlines by subject
- Auto-save and load — all data persists in JSON files
