# Student Daily Planner & Streak Tracker

A console-based productivity tool that helps students track daily tasks, build completion streaks, log study time, and set reminders with all data saved permanently using JSON files.

## Project Overview

Student Daily Planner & Streak Tracker is designed to help students stay organized and motivated. Users can create daily task checklists, mark items complete, and maintain a completion streak; a running count of consecutive days they have finished tasks. Study sessions can be timed and logged, and reminders help keep track of important deadlines. All data is stored in JSON format, so progress is always saved even when the program is closed.

### Core Features
- Daily task checklist - add, view, edit, delete tasks
- Completion streak system - tracks current and longest streaks
- Task history and statistics - completion rates, productivity trends
- Study timer - records study minutes per session
- Reminders - set and view upcoming deadlines
- Auto-save and load - all data persists in JSON files
